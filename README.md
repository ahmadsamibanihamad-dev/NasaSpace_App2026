# AgriVision

منصة دعم قرار زراعي لمزارع **الأردن فقط**، ضمن تحدي NASA Space Apps «Field Shift».

في الموقع جزءان:

- **عمل فريق الذكاء الاصطناعي** في `backend/nasa_final/`: التوقعات، ترتيب المحاصيل الستة، ومخطط الدورة الزراعية.
- **التحليلات الستة** (ملاءمة محصول، اقتراح محاصيل، تقويم الزراعة، دورة زراعية، احتياجات مائية، مخاطر): من محرك قواعد في `backend/app/engine/` يعمل على 13 محصولاً والمناخ التاريخي من NASA POWER. هذا الجزء ليس من ملفات الفريق.

> **البيانات تاريخية:** التوقعات تُحسب لتاريخ زراعة يختاره المستخدم داخل بيانات الفريق (حتى 31 آب 2026). ليست توقعاً حياً لطقس اليوم، والموقع يذكر ذلك في كل صفحة تعرض توقعاً.

## ماذا يفعل الموقع

| الصفحة | الوظيفة |
|---|---|
| جرّب بدون حساب | الضيف يحدد موقعه ويرى التوقعات والمحاصيل المرتبة وخطة الدورة. لا يُحفظ شيء |
| مزرعتي | رسم القطع على الخريطة أو إدخال إحداثياتها، مع المساحة والمحيط ومعلومات التربة التلقائية |
| التوقعات | توقع الحرارة والرطوبة ورطوبة سطح التربة والأمطار لثلاثين وتسعين يوماً من تاريخ الزراعة، وثلاثة محاصيل مرتبة لكل فترة. الترتيب متعدد العوامل: المناخ، الماء، التربة، الخصوبة، والدورة الزراعية حسب المحصول السابق، مع درجة وتفسير لكل عامل |
| مخطط الدورة الزراعية | خطة متتابعة لتسعين يوماً: محصول قصير للأيام 1–30 ثم محصول أطول للأيام 31–90، مع خط زمني وبدائل وشرح وتنبيهات |
| الخطط المحفوظة | خطط الدورة التي حفظها المستخدم: عرض، مقارنة خطتين، طباعة، حذف |
| تحليل جديد | ستة تحليلات على 13 محصولاً: ملاءمة محصول، اقتراح محاصيل، أفضل فترة للزراعة، دورة زراعية، احتياجات مائية، مخاطر |
| المخاطر | مركز المخاطر لآخر تقييم |
| التقارير | سجل التحليلات: عرض، مقارنة تحليلين، حذف |
| التحليلات البيئية | سلاسل زمنية مرصودة للحرارة والأمطار ورطوبة التربة والرطوبة والإشعاع |
| الإعدادات | المزارع، الحساب، اللغة، وحدات المساحة، مصدر الخريطة |

التوقعات ومخطط الدورة يعملان على محاصيل الفريق الستة: الفجل، الجرجير، السبانخ الصغيرة (قصيرة المدة)، والجزر، الشمندر، الفاصولياء الخضراء (أطول مدة). التحليلات الستة تعمل على 13 محصولاً آخر: قمح، شعير، عدس، حمص، بيقيا، بندورة، خيار، بطاطا، بصل، باذنجان، زيتون، نخيل التمر، حمضيات. المجموعتان لا تتقاطعان، لأن جدول الفريق لا يحوي البيانات التي تحتاجها التحليلات (معاملات الماء، مراحل النمو، حدود الصقيع).

## التشغيل على Windows

المتطلبات: Node.js 20 أو أحدث، و Python 3.11 أو أحدث.

انقر نقراً مزدوجاً على `start.bat`. يثبّت الاعتماديات في أول مرة، يفتح نافذة ثانية للخادم على المنفذ 8765، ينتظر حتى يجهز، ثم يشغّل الموقع ويفتح المتصفح. أبقِ النافذتين مفتوحتين.

يدوياً: شغّل الخادم كما في [backend/README.md](backend/README.md)، ثم:

```bash
cd frontend
```

```bash
npm install
```

```bash
npm run dev
```

ثم افتح <http://localhost:5173>.

**ملف البيانات الرئيسي للفريق** (47 ميغابايت) غير مرفوع على git. انسخه من `NASA_FINAL.zip` إلى `backend/nasa_final/data/processed/master_2019_2026/`. بدونه يعمل تاريخ الزراعة الافتراضي فقط (2 أيار 2026).

### التجربة السريعة

1. من الصفحة الرئيسية اضغط «جرّب بدون حساب»، أو أنشئ حساباً.
2. في معالج الإعداد اضغط «أو جرّب بمزرعة تجريبية» لإنشاء «مزرعة الحصن» (ست قطع، وعليها شارة «بيانات تجريبية»).
3. افتح «مخطط الدورة الزراعية»، غيّر تاريخ الزراعة والمحصول السابق، ثم احفظ الخطة.

## حدود يجب معرفتها

- **التوقع ليس حياً.** لا يوجد ربط يومي بمصادر البيانات.
- **درجات الملاءمة والدورة مؤشرات قواعد تجريبية** غير معايرة محلياً، وليست احتمال نجاح.
- **مراجع متطلبات المحاصيل** نشرات إرشادية من جامعتي يوتا ومينيسوتا الأمريكيتين، استُخدمت نوعياً (القوام المفضل، الصرف، الاحتياج النسبي). لم يُتحقق من أي منها على بيانات حقلية أردنية.
- **حموضة التربة في البيانات 7.5–8.2 في كل الأردن**، أعلى من نطاق خمسة من المحاصيل الستة، فعامل الحموضة يخفض كل الدرجات تقريباً.
- **توقع الأمطار ضعيف الدقة.** توقعا 30 و90 يوماً يُحسبان بطريقتين مختلفتين وقد يتعارضان (مجموع 90 يوماً أقل من مجموع 30). عندها لا تُصحَّح القيمة، وتُعرض خطة جزئية بمحصول أول فقط مع تنبيه. في عيّنة من عشرة مواقع كان التعارض في كل المواقع عند تاريخ 2 أيار 2026 و20 كانون الأول 2025، وفي ثلاثة مواقع عند 15 آذار 2026.
- ظروف المرحلة الثانية (الأيام 31–90) مشتقة حسابياً من التوقعين، وليست توقعاً مستقلاً.
- خمس نقاط شبكية بلا بيانات تربة، منها وسط إربد ووسط عمّان.
- النماذج دُرّبت بـ xgboost 3.4.1 (يحتاج Python 3.12) وتعمل هنا على xgboost 3.2 مع Python 3.11. تُحمَّل دون تحذيرات، لكن تطابق الأرقام مع 3.4.1 لم يُتحقق منه.
- استعادة كلمة المرور والإشعارات واجهة فقط. الطباعة إلى PDF عبر المتصفح.
- الموقع يعمل محلياً، وغير منشور على خادم عام.
